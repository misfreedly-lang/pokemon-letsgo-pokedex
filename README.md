# ⚡ 예서 & 서우의 렛츠고 포켓몬 모험 도감 & 한글 쓰기 교실 🎮

닌텐도 스위치 **《포켓몬스터 레츠고! 피카츄 / 레츠고! 이브이》**를 플레이하는 아이들을 위한 웹 도감 & 한글 쓰기 학습 웹앱입니다.

## 🌟 주요 기능
- **트레이너 선택 (다중 프로필):** 예서(피카츄)와 서우(이브이) 각각의 독립된 진도 및 도감 저장 (브라우저 로컬 저장)
- **진도별 맞춤 도감:** 태초마을부터 상록숲, 회색시티(웅이), 3·4번 도로, 달맞이산, 블루시티까지 진도별 필터링
- **포획 체크:** 내가 잡은 포켓몬을 체크하고 도감 완성도 확인
- **태블릿 펜슬 한글 쓰기:** 아이패드/갤럭시탭 등에서 애플펜슬/S펜/터치로 포켓몬 이름 따라 쓰기 (펜, 부분 지우개, 싹 지우기, 칭찬 도장)
- **상성 & 배틀 시뮬레이터:** 1대1 상성 분석 및 승리 비법 가이드
- **게임 공략 노트:** 회색시티 웅이 공략, 3번 도로 푸린 잡기, 4번 도로 500원 잉어킹(갸라도스), 달맞이산 달의돌 진화 등
